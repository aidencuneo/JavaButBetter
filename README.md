# JavaButBetter

## Usage

1. Place **jbb.jar** in your project
2. Run `java -jar jbb.jar <src_folder> <dest_folder>`, where:
    - **src_folder** = folder full of .jbb files to compile
    - **dest_folder** = resulting folder full of .java files

## Development

1. Run **recompile.bat** to compile **src** to **src_out**
2. Run **test.bat** to use **src_out** to compile **src_jbb** to **src_jbb_out**
